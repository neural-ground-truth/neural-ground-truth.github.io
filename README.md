# Neural Ground Truth

Where research meets intuition. Papers, concepts, and code — grounded.

Welcome to the source code for **Neural Ground Truth**, a technical blog focused on breaking down complex machine learning architectures, training methodologies, and novel algorithms into digestible, visual, and code-backed explainers.

## Focus Areas
- **Foundations:** Deep dives into Attention, Tokenization, and decoding strategies.
- **LLMs & Speech:** Architectural comparisons and efficiency improvements.
- **Low-Resource NLP:** Challenges and solutions for languages with limited training data.

## Local Development

All commands are run from the root of the project:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
